# ADR 0003: Стиль API та модель помилок

## Статус
Прийнято, 2026-09-16.

## Рішення
- Стиль API — **REST** поверх HTTP, JSON у тілі запиту/відповіді.
- Коди відповідей відповідають семантиці HTTP:
  `201` — створено, `200` — успіх, `204` — видалено без тіла,
  `400` — помилка валідації, `404` — не знайдено.
- **Єдиний формат помилки** для всіх endpoint'ів:
  ```json
  {
    "error": "ValidationError",
    "code": "CLIENT_ID_REQUIRED",
    "details": [{ "field": "clientId", "message": "clientId is required" }]
  }
  ```
  - `error` — тип помилки (`ValidationError`, `NotFoundError`, ...).
  - `code` — машинно-читаний код, може бути `null`.
  - `details` — масив пояснень по конкретних полях, може бути `null`.
- Специфікація API описується в `docs/api/openapi.yaml` і є джерелом
  правди для контракту — реалізація повинна відповідати їй.
