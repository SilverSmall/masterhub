Roadmap: MasterHub

Плани команди на найближчі 3–4 тижні після завершення MVP (клієнт → бекенд → БД).

Тиждень 3 — новий endpoint
Додати POST /items для створення нового майстра/послуги вручну (поки без валідації — базовий CRUD-старт).
Оновити клієнтську сторінку: форма додавання майстра поруч із кнопкою "Load items".

 4 — базова авторизація
Реалізувати реєстрацію та логін клієнта/майстра (email + пароль).
Захистити endpoint створення майстра — тільки для автентифікованих користувачів із роллю "майстер".

Тиждень 5 — CRUD для замовлень (Order)
Додати сутність Order (замовлення клієнта в майстра): POST /orders, GET /orders, GET /orders/{id}, PUT /orders/{id} (зміна статусу), DELETE /orders/{id}.
Пов'язати замовлення з конкретним майстром і клієнтом.

Тиждень 6 (орієнтовно) — верифікація майстрів (Verification/Moderation)
Додати статус верифікації майстра (pending, verified, rejected).
Простий інтерфейс модератора для підтвердження заявок.

Тиждень 7 (орієнтовно) — відгуки та рейтинги (Reviews & Ratings)
Додати сутність Review (відгук клієнта на майстра після виконаного замовлення).
Показувати середній рейтинг майстра на його профілі та в результатах пошуку.

Роадмап буде уточнюватись за результатами кожної практичної роботи курсу (Domain-Driven Design, вибір архітектурного стилю, контракт API тощо). Модулі Auth, Verification, Notifications, Payments і Reviews & Ratings з архітектурної діаграми поступово перетворяться саме на ці етапи роадмапу.
