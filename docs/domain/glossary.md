Глосарій термінів (Ubiquitous Language) — MasterHub

Master (Майстер) Верифікований або незверифікований користувач-виконавець, який пропонує послуги на платформі.

Client (Клієнт) Користувач, який шукає й замовляє послугу майстра.

Service (Послуга) Конкретний вид роботи, який пропонує майстер (наприклад, "заміна змішувача"), з фіксованою ціною.

Order (Замовлення) Бронювання клієнтом послуги у конкретного майстра на конкретну дату/час.

Verification (Верифікація) Процес підтвердження документів і кваліфікації майстра модератором. Без верифікації майстер має обмежену видимість у пошуку.

Review (Відгук) Оцінка (1–5) та коментар клієнта про виконане замовлення; впливає на рейтинг майстра.

Payment (Оплата) Транзакція оплати клієнтом виконаного замовлення через платформу.

Status (Статус) Термін, що має різне значення в різних піддоменах — див. уточнення нижче.

Уточнення терміну "Status" у різних піддоменах
У Booking: статус замовлення — pending / confirmed / done / cancelled.
У Payments: статус оплати — pending / paid / failed.
У Verification: статус заявки майстра — pending / verified / rejected.

Щоб уникнути плутанини в коді та документації, кожен статус називається повним іменем: orderStatus, paymentStatus, verificationStatus — а не просто status.
